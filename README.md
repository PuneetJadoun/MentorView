# Typeform Clone — SDE Fullstack Assignment

A functional clone of Typeform's form builder and conversational respondent experience.

> Status: scaffolding in progress. Full README (setup instructions, tech stack, architecture overview, database schema, assumptions) will be filled in as implementation lands — see `docs/` for design docs in the meantime.

## Repo layout

- `frontend/` — Next.js (TypeScript) app: builder UI, respondent flow, results dashboard
- `backend/` — FastAPI app: forms/questions/responses API, SQLite persistence
- `docs/` — design docs (architecture, DB schema, API spec, UI notes, task breakdown)
- `assets/screenshots/` — UI screenshots for the README/demo
- `assignment.md` — original assignment brief
